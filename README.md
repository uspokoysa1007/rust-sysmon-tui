> Легковесный, быстрый и красивый консольный монитор системных ресурсов на Rust с использованием **Ratatui**, **Sysinfo** и **Crossterm**.

```text
┌────────────────────────── ⚡ RUST SYSTEM MONITOR (TUI) ⚡ ──────────────────────────┐
│                                                                                     │
│ ┌─ CPU Usage ───────────┐ ┌─ RAM Usage ───────────────────────────────────────────┐ │
│ │ ████████░░░░░░  42.5% │ │ ████████████░░░░░░░░  7.82 GB / 15.93 GB (49.1%)      │ │
│ └───────────────────────┘ └───────────────────────────────────────────────────────┘ │
│                                                                                     │
│ ┌─ Disks ───────────────┐ ┌─ Top Processes (by RAM) ──────────────────────────────┐ │
│ │ 💾 C:\: 142.1/476.2 GB│ │ PID     Name                Memory      CPU           │ │
│ │ 💾 D:\: 820.0/931.5 GB│ │ 14208   chrome.exe          842.1 MB    3.2%          │ │
│ └───────────────────────┘ └───────────────────────────────────────────────────────┘ │
│                      Нажмите [q] или [Esc] для выхода                               │
└─────────────────────────────────────────────────────────────────────────────────────┘
```

## ✨ Возможности
- 📈 **Мониторинг процессора:** динамический индикатор нагрузки CPU с цветовой шкалой (зеленый / желтый / красный).
- 🧠 **Оперативная память:** использование RAM и процент заполнения в реальном времени.
- 💾 **Статус накопителей:** отображение всех дисков, свободного и занятого места.
- ⚙️ **Топ процессов:** мониторинг наиболее ресурсоемких процессов по оперативной памяти с их PID и процентом CPU.
- ⚡ **Низкий оверхед:** минимальное потребление ресурсов благодаря Rust.
- 🔄 **Частота обновления:** 500 миллисекунд.

## 🚀 Быстрый старт

### 1. Готовый бинарник (без установки компилятора)
Скачайте архив из раздела [Releases] или возьмите готовый файл из папки `release-package/`:
```powershell
.\rust-sysmon-tui.exe
```

### 2. Сборка из исходников
Для сборки требуется компилятор **Rust** (1.75+):
```powershell
git clone <URL_РЕПОЗИТОРИЯ>
cd rust-sysmon-tui
cargo run --release
```

## 🛠 Стек технологий
- [ratatui](https://github.com/ratatui/ratatui) — библиотека для рендеринга терминальных интерфейсов (TUI).
- [crossterm](https://github.com/crossterm-rs/crossterm) — кроссплатформенное управление экраном и событиями ввода.
- [sysinfo](https://github.com/GuillaumeGomez/sysinfo) — кроссплатформенный сбор метрик ОС.
